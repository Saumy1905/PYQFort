  ## Detailed Syllabus

  ### **Module 1: Basic Computer Organization**
    - Functional units of a computer.
    - Basic operational concepts.
    - Bus structures and data representation.

  ### **Module 2: Register Transfer and Microoperations**
    - Register transfer language.
    - Arithmetic, logical and shift microoperations.

  ### **Module 3: Central Processing Unit**
    - Instruction formats and addressing modes.
    - Control unit: hardwired and microprogrammed.
    - Stack organization.

  ### **Module 4: Memory Organization**
    - Memory hierarchy, cache memory.
    - Main memory, auxiliary memory.
    - Virtual memory and memory management.

  ### **Module 5: Input-Output Organization**
    - Peripheral devices, I/O interface.
    - Modes of transfer, interrupts.
    - Direct Memory Access (DMA).

  ### **Module 6: Pipeline and Vector Processing**
    - Parallel processing, pipelining.
    - Arithmetic and instruction pipeline.
    - Vector processing.
